## commandes possible du bot:
        /pro-perso
pour savoir si c'est un voyage pro ou perso (on oriante les questions)<br>
BOUTON

        /weather
pour avoir le temps (pluie, soleil, ...)

        /depart
pour avoir la ville de départ

        /arrivée
pour avoir la ville d'arrivée

        /destination
pour avoir l'avis de l'utilisateur s'il préfère ville/campagne

        /transport
pour avoir les transports en commun dispo dans la ville

        /date
l'utilisateur donne la date prévue (pour les autres prédictions)

        /logement
pour avoir les logements disponibles dans la ville

        /activités
donne les activités faisable autour de la ville choisie
        

        /recap
faisable a tout moment, on demande au bot de stopper la discution pour avoir une fiche récap de l'interaction
