# Éthique

## Utilisations des données
L'utilisation des données de l'utilisateur est nécessaire pour répondre aux questions de celui-ci.<br>
Elles sont également utilisés pour produire une petite fiche récapitulative à la fin de l'entretien entre l'utilisateur et le chatbot.
Il n'y a pas de transfert de données entre chaque chat, ce qui implique qu'a la suppression d'un chat, toutes les données associées seront supprimées dans le même temps.
Pour ce qui est du stocage des données de l'utilisateur, elles seront stoquées localement en cache. D'aucune autre manière, ce qui réduit considérablement les risques.

## Risques
Les risques possible avec le chatbot sont :
- collecte des informations de l'utilisateur(réduit avec un système de cache)
- réponses qui manques de cohérences à cause des données d'entrainement
- confiance accordée au chatbot (qui peux se tromper)
- réponses trop lente, expérience de l'utilisateur moindre
